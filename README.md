Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) competition on [make.fun](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5).

This program outputs an original, single-line dad joke about a father giving his son a broken camping gift as a straight-faced lesson in self-reliance, formatted within the 200-character UTF-8 limit.

## Run it

```sh
node main.ts
```

By default, `main.ts` writes the entry text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when `MAKEFUN_OUTPUT_DIR` is set) with mode `0644`. In the competition sandbox, the grader executes `node /bot/main.ts`.
